# 结构体
# PS 参考内容：1. 《C Primer Plus》：指针、结构体、结构体内存对齐章节      2.数据结构与算法：链表基础概念

## 1. PerInfo结构体定义（typedef别名）

```
typedef struct {
    char name[10];    // 个人姓名，字符数组，10字节
    char gender;      // 性别，字符型
    int age;          // 年龄，整型
    double height;    // 身高，双精度浮点型
} PerInfo;
```


 typedef作用：为结构体类型起别名PerInfo，后续定义变量无需写struct关键字，直接使用PerInfo。

## 2. 结构体指针含义

结构体指针是存储**结构体变量起始内存地址**的指针变量。

- 若`PerInfo p; PerInfo *ptr = &p;`，`ptr`保存结构体`p`的首地址。
    `ptr->age`：箭头运算符，结构体指针访问成员

## 3. 结构体内存对齐与大小计算

 
 规则：每个成员起始地址必须是自身类型字节数的整数倍；结构体整体大小必须等于最大基础成员字节数的整数倍，不足则填充空字节。

成员依次：

1. `char name[10]`：占10字节（地址0~9）
2. `char gender`：占1字节（地址10），累计11字节
3. 下一个成员`int`占4字节，起始地址需要是4的倍数。11之后填充1个字节，`age`从地址12开始，占用4字节，累计16字节
4. 下一个成员`double`占8字节

**`sizeof(PerInfo) = 24`**
