# step1.什么是树
### 1. 树与二叉树的定义
树是一种非线性的数据结构，由若干节点组成。它有唯一的根节点，剩余节点可以拆分成多个互不相交的子树，整体不存在回路。

二叉树是树的特例，它规定每个节点最多拥有两个子节点，也就是左孩子和右孩子，左右子树是有顺序区分的，不能随意互换。

### 2. C语言中二叉树的存储方式，以及二叉树的特点
存储方式：
1. 链式存储
用结构体来定义节点，一个成员存放数据，两个指针分别指向左孩子、右孩子。
```c
typedef struct BiTNode{
    int data;
    struct BiTNode *lchild, *rchild;
}BiTNode;
```

2. 顺序存储（数组）
一般只适合完全二叉树，按照层序把节点依次存入数组，依靠下标来计算父子节点的位置。普通二叉树用这种方式会产生大量空间浪费。

二叉树特点：
1. 非线性结构；每个节点最多2个子节点，左、右子树需要区分。
2. 根节点没有父节点，叶子节点没有子节点。
3. 包含n个节点的二叉树，边的总数一定是n-1。
4. 二叉树第i层，最多存在 2^(i-1) 个节点；深度为k的二叉树，最多有 2^k-1 个节点。
