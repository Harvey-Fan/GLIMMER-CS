# Step2: 反物质珍珠 —— 整数溢出与二进制下的运算

## 任务 2.1：

**由题目得：**
- 当前珍珠数量：88（二进制 `01011000`）
- 投入珍珠数量：65（二进制 `01000001`）
- 8位有符号补码计数器范围：[-128, 127]

### 1. 两个 8 位补码相加后，寄存器中实际保存的二进制位模式是多少？

`01011000` (88) + `01000001` (65) = `10011001` (二进制)

### 2. 转换为十进制后，系统认为杯子里现在有多少颗珍珠？这是正溢出还是负溢出？

**思考过程：**
- `10011001` 作为 8 位有符号补码，最高位为 1，表示负数。
- 取反加一求绝对值：取反 `01100110`，加一得 `01100111`，即 103。
- 所以系统认为珍珠数量为 **-103** 颗。
- 这是因为两个正数相加结果超出了 8 位有符号整数的最大值 (127)，发生了 **正溢出**。(根据那个环可以看出来，到了负数区域)

### 3. 补全 C 语言检测函数，如下

```c
// 若相加不发生溢出返回 1，发生溢出返回 0
int is_safe(int x, int y) {
    int sum = x + y;
    int x_sign = (x >> 31) & 1;
    int y_sign = (y >> 31) & 1;
    int sum_sign = (sum >> 31) & 1;//按位与是为了只保留第一位，结果只有0和1
    int result;
    //如果最高位是 1（负数），右移后，前面会补 1，变成一个全是 1 的二进制数（即十进制的 -1）。如果最高位是 0（正数），右移后变成 0。
    //ps 如果是无符号，左边一律补0，而对有符号数，左边补的是符号位
    // 请补全代码写在 TO DO 与 END OF TO DO 之间:
    // TO DO
    // 溢出条件：两数同号，且结果符号与它们不同
    if (x_sign == y_sign && sum_sign != x_sign) {//相加变号了说明溢出
        result = 0; //溢出的情况只有两种：
//1. 正数 + 正数 = 负数（结果超出了正数的最大值，进位到了符号位，变成了负数）。
//2. 负数 + 负数 = 正数（结果超出了负数的最小值，借位导致符号位变成了 0）
//注意！异号是不可能溢出的，因为本来范围就是沿0对称分布，数学问题
    } else {
        result = 1; // 安全
    }
    // END OF TO DO

    return result;
}
```

29 = 32 - 3 = 32 - 2 - 1
